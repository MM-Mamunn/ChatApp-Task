# Follow Relevant Skills

## Purpose

Skills provide task-specific instructions, workflows, constraints, and quality checks. Before carrying out a task, identify and follow every skill that applies.

## Required Workflow

1. **Identify available skills.** Inspect the skill directories or skill registry available in the current environment. Also check for project-specific skills when working inside a repository.
2. **Determine relevance.** Match the task to the descriptions and scope of the available skills. If multiple skills apply, use all of them. Skip skills that are genuinely unrelated to the task.
3. **Read the full instructions.** Before acting, read the complete `SKILL.md` for every relevant skill. Follow any additional files, references, scripts, or procedures that those instructions explicitly require you to consult.
4. **Apply the instructions throughout the task.** Follow the relevant skills' required workflows, tool usage, constraints, output formats, and verification steps. Do not ignore, abbreviate, or selectively follow applicable requirements.
5. **Respect instruction priority.** Follow higher-priority system and developer instructions first, then the user's task requirements and applicable skill guidance. If relevant instructions conflict and the conflict cannot be resolved safely, explain the conflict and ask for clarification when needed.
6. **Verify before finishing.** Check that the work complies with the applicable skill instructions and task requirements. Run the required checks when possible, and report what was actually verified. Never claim that a check passed unless it was performed successfully.

## Scope and Efficiency

- Use only skills relevant to the current task; do not perform unrelated work merely because another skill is available.
- Do not assume a skill is irrelevant based only on its name. Read its description and inspect its instructions when applicability is uncertain.
- Do not make changes outside the requested scope.
- If a required skill or referenced resource is unavailable, state the limitation rather than pretending to have read or followed it.
- Re-check applicable skills when the task changes materially or a new kind of work is introduced.

## Completion Standard

Complete the requested task only after applying all relevant skill instructions and performing the applicable verification. Keep the final report accurate and concise, including any unresolved issues or checks that could not be performed.
